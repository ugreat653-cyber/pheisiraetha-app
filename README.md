# PHEISIRAETHA

PHEISIRAETHA is a local-first system for tracking the path from intention to observable outcome through repeated check-ins.

**Current version: v0.1 Beta 1** (`v0.1-beta.1`). Status: limited public beta.

[Open PHEISIRAETHA](https://ugreat653-cyber.github.io/pheisiraetha-app/) · [First-user guide](BETA_TESTING.md) · [Feedback / GitHub Issues](https://github.com/ugreat653-cyber/pheisiraetha-app/issues)

## What it does

Define one intention, record how it develops, and review its progression over time:

- **RIS — Ratified Intent State:** your objective, success criteria, scope, non-goals, constraints and rationale.
- **Repeated check-ins:** a Current Intention Snapshot (CIE), an Intent & Energy Profile (IEP), and an Observed Outcome Profile (OOP).
- **Intentional Revision:** deliberately keep or revise the intention. Recording a changed outcome is separate from choosing to change the intention itself.
- **History:** review saved check-ins and revisions.
- **Local JSON backup:** export and import your record through Data.

The beta includes onboarding, a cinematic launch splash, a responsive mobile interface, keyboard/accessibility improvements, and an offline app shell after an initial online load.

PHEISIRAETHA supports self-reflection and observation. It does not establish that thoughts, emotions, intentions or effort cause external events. It is not medical or psychological treatment.

## Install or use in a browser

Live URL: **https://ugreat653-cyber.github.io/pheisiraetha-app/**

### Android / Chrome

1. Open the live URL in Chrome.
2. Use **Install app** or **Add to Home screen** in the browser menu, if available.
3. Open the installed PWA from its app icon.

### iPhone / Safari

1. Open the live URL in Safari.
2. Tap **Share**.
3. Choose **Add to Home Screen** and confirm.
4. Launch PHEISIRAETHA from the Home Screen.

### Desktop

Open the live URL in a supported Chromium browser. Use the install icon or **Install app**, if available, or use PHEISIRAETHA directly in the browser.

Installation controls and the system launch/splash experience vary by operating system and browser version. Load the app online once before using its offline app shell.

## Privacy and local data

Current v0.1 Beta stores entries locally in the browser/PWA on the current device. There is **no account, no cloud database, no server sync and no advertising SDK**. No cloud synchronization is provided; your entries remain in the current device/browser and do not automatically follow you to another browser or device.

If the data matters to you, use **Data → Export backup (JSON)** and keep the exported file somewhere safe. Treat backups as private: they contain your entries.

**Deleting or clearing browser/PWA site or app data may permanently remove locally stored PHEISIRAETHA data unless you have exported a backup.** Keep a backup before changing browsers/devices or removing site data.

## Beta feedback

Follow [BETA_TESTING.md](BETA_TESTING.md) and report problems or feedback through [GitHub Issues](https://github.com/ugreat653-cyber/pheisiraetha-app/issues). Include your device, OS, browser or installed-PWA status, app language, what happened, what you expected and steps to reproduce. Screenshots are optional.

**Do not include sensitive personal information in public GitHub Issues.** Do not attach a private JSON backup or publish your real intention, RIS or CIE text. If a problem depends on form content, describe its shape or use a harmless example instead. Check screenshots for private information before sharing them.
