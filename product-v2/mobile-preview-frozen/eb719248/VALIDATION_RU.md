# PHEISI — проверка отдельной мобильной preview-версии

Дата: 15.10.2026. Область: отдельный приватный Sites-проект `appgprj_6ad0ea446798819185547a04e5655bc4`.

## Реализовано

- Несколько независимых намерений со стабильными внутренними ID и собственной историей.
- RIS с шестью примерами. Примеры не становятся пользовательскими ответами.
- Создание намерения → продолжение IEP/OOP → проверка ответов → явное сохранение завершённого наблюдения.
- Один сохраняемый черновик на намерение. Автосохранение, «Сохранить и завершить позже», восстановление после перезагрузки и работа без сети после первоначальной загрузки.
- Повторное наблюдение требует явного подтверждения текущей формулировки намерения. Изменение RIS сохраняется вместе с наблюдением; прежние CIE и история остаются прежними.
- RU/EN, адаптивный интерфейс, улучшенный контраст и короткое имя PHEISI для установки на главный экран.
- Экспорт настоящего файла backup. Импорт добавляет копии с новыми внутренними ID, сохраняя исходное содержимое и владение черновиками.
- Старый JSON v0.1 можно импортировать вручную отдельной копией. Автоматического переноса данных основной версии нет.

## Правила завершения в preview

Обязательны шесть непустых полей RIS. Для наблюдения обязательны явно введённые числовые ответы: желание, вера, сила эмоции, умственные и практические усилия, часы действий, достигнутая часть результата. Дополнительно выбираются эмоция, частота внимания, направление изменений, хотя бы одно основание наблюдения и ответ о намеренном изменении RIS. Для повторного наблюдения требуется подтверждение сохранённого RIS.

Действия, описание текущей ситуации, события и внешние обстоятельства — необязательные текстовые поля. Числовые поля изначально пусты; ноль считается ответом только после ввода. Завершение требует отдельной кнопки пользователя. Это правила экспериментальной версии; правила production не менялись.

## Данные и сбои

База: `pheisiraetha_mobile_preview_v2` на отдельном origin. Foundation скопирован побайтно из `source/product-v2/storage.mjs`. Импорт модуля не выполняет I/O.

Завершение наблюдения записывает историю, изменение RIS, удаление черновика, ревизии и квитанцию операции одной транзакцией IndexedDB. Результат возвращается после завершения транзакции. Повтор того же operationId воспроизводит результат; другой запрос с тем же ID отклоняется. CAS блокирует перезапись устаревшим черновиком.

Импорт проверяет граф владения, версии, исходные снимки и допустимость итоговой структуры до записи. Неподдерживаемые, повреждённые и слишком глубоко вложенные backup не меняют существующие записи. Codec сохраняет в непрозрачных данных signed zero, нечисловые и бесконечные числа, инертный собственный ключ __proto__.

Автосохранение выполняется с задержкой 350 мс. Переходы и явное сохранение ожидают commit. При принудительном закрытии до commit последние изменения могут не сохраниться; интерфейс показывает статус. Очистка данных браузера может удалить локальную базу. Резервная копия необходима для переноса и восстановления.

## Изоляция и ограничения

Production main, защищённый baseline, development, PR #8, GitHub Pages и исторические rollback-артефакты не изменялись этой работой. Preview публикуется через отдельный Sites-проект и собственный репозиторий исходников.

Frozen Analysis и Safety не изменены и не подключены к preview. Аналитика явно недоступна; приложение показывает сохранённые ответы без аналитических заключений.

Preview поддерживает RU/EN. Полные 31 локаль, RTL, полноценная проверка экранным диктором, подписка, аккаунт приложения и синхронизация устройств остаются будущими этапами. Приватный доступ Sites требует входа владельца; это не аккаунт и не синхронизация данных приложения.

История на экране краткая; полные записи сохраняются в базе и backup. Формат backup preview отличается от legacy v0.1; старый OFF не умеет читать эту новую модель и не должен получать её через подмену прежнего ключа данных.

Физические iPhone и Samsung ещё не проверены. Порядок ручной проверки приведён в README_RU.md.
